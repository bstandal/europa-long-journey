# Harvest native editor-review package

`harvest-native-draft-v1.json` is a complete decision object for the bounded
Harvest laboratory scene. It is not public content and cannot enter a package.
Its status remains `DRAFT_AWAITING_EDITOR_APPROVAL` until the editor-in-chief
acts on the manuscript and interaction recommendation.

The recommendation replaces an exact hidden `5/4/3` answer with three visible
minimum obligations and three genuinely allocable surplus shares. The user may
reverse every transfer before commit. Every valid final distribution preserves
its exact local material state but produces the same approved historical world
effect. The scene therefore exposes scarcity and deferred use without victory,
failure, alternative history or a concealed quiz answer.

The public-facing draft contains no source apparatus, scholarly caveat or
methodological language. Authority hashes and the F1–F7 review stay in this
backstage package.
