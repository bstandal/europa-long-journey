# Longhouse portrait directions

These files are non-shipping composition studies generated with the built-in
Codex image tool. The exact prompt for each image is stored beside it. Image 1
in the three initial generation prompts was the existing web subject reference;
Image 2 was the Harvest franchise reference. A2 is a precise edit of A. A3–A6
are versioned refinement studies; their prompt files identify the exact edit
target for each pass.

[`../selection.json`](../selection.json) records the provisional selection,
visible rejections and mandatory refinement gate. None of these images is a
production master, layer source or package asset.

[`../refinement-review-a5-a6.json`](../refinement-review-a5-a6.json) records
the 390-point review that rejects A5 and A6 while leaving A4 as the provisional
composition base.
