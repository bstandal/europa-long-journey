# Harvest responsive audio work object

This directory contains the editable, provisional audio construction for
`The Harvest Had to Last`. It cannot enter a shipping package.

`score-source.json` holds the shared motif vocabulary and every note, tempo,
dynamic, articulation, instrument binding and stem entry for the five runtime
regions. `soundscape-source.json` binds rain, hearth, grain, fibre and visible
settlement work to deterministic local synthesis. It also divides the broad
environment from near spatial material and names every authored silence.

`work-object.json` is the runtime projection. Its approach and consequence are
finite. Waiting, engaged and resistance are three separate 15-second timelines
that retain one sample position when the interaction state changes. Loop beds
contain no narration and no timed haptics. The Allocate reducer supplies
`contact`, `resistance`, `transfer` and the durable `seal`; `drag` and `break`
remain in the canonical vocabulary for other grammars.

`render-receipt.json` binds the source documents, native runtime contracts,
renderer, local binaries, SoundFont, licence notice and 75 rendered outputs.
The ignored `../cache/harvest-responsive-v1/` directory contains 48 kHz,
24-bit stereo MIDI stems, score stems, material layers, runtime masters and
offline previews. `npm run render:harvest-audio` rebuilds that directory twice
and accepts it only when every output hash is identical. `npm run
validate:harvest-audio` rechecks the recorded bytes without rendering.

The two narration slots deliberately have no asset. They bind the current
manuscript segment hashes and remain release-blocking until the editor-selected
voice has an exact-word master. Loudness calibration, artistic approval,
editor approval, physical-device review and shipping approval remain open.
