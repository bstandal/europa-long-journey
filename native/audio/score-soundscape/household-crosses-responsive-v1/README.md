# Household Crosses responsive audio sources

This directory holds the editable score and soundscape sources for `The Field
Crosses the Sea`. The sources and generated work object remain
`PROVISIONAL_NON_SHIPPING` and are excluded from shipping packages.

The 5/4 score begins with four separated material tones: seed, animal, tool and
learned practice. Contrabass holds the shore, cello carries the household tones
and dulcimer carries work. Only the consequence joins the four tones as the
`returning-field` figure. `farming-belt-held` is forbidden here.

The soundscape binds close water, animal weight, seed sacks, carrying fibre and
the timber craft body with carried tools to visible sources. The procedural
water layer claims only close shallows, wake and close river water. It makes no
claim about a sail, mast, rigging, wind propulsion, a specific paddle or oar,
rowing cadence, plank construction, keel, deck, nails, metal fittings, storm or
heroic ocean. Herd synthesis cannot produce species calls, bells, tack, gallop
or stampede. No imported recording or network service is used.

The source contract contains five regions: a finite 60-second approach, three
sample-aligned 15-second interaction beds and a finite 55-second consequence.
Every region has three score stems, five independently rendered material layers
and one sample-bound silence window. Narration and timed haptics remain outside
the loop beds. The Trace reducer owns origin and accepted-anchor `contact`,
throttled viable-route `drag`, and the durable destination `seal`; the
destination never emits preliminary contact.

Narration remains missing. `ff-crossing-02` also retains an unresolved F5
sowing-season editor decision. The work object must preserve both shipping
blocks without changing the approved prose. Artistic, editor, physical-device
and shipping approval remain open.

Run:

```sh
cd native/tooling
npm run render:household-crosses-audio
npm run validate:household-crosses-audio
```

Rendering performs two complete offline passes and accepts the evidence only
when every output byte matches.
