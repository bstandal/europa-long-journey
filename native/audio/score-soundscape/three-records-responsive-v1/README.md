# Three Records responsive audio sources

This directory holds the editable score and soundscape sources for `Set the
Records Together`. The sources and generated work object remain
`PROVISIONAL_NON_SHIPPING` and cannot enter a shipping package.

The 5/4 score keeps the earth fifth and D–E–D river return beneath three
separated record tones. Contrabass holds the gorge, cello carries the route and
dulcimer carries D, F and A. Bassoon appears only in the resistance bed and
only for `resistance-knot`. The restrained `returning-field` figure enters in
the consequence after farming has entered the river settlement.

Seven source-bound material loops carry the causal mix: gorge current, river
gear, landing work, hearths, grain, domestic animals and non-lexical household
presence. Waiting, engaged and resistance reuse the same seven 15-second loop
files and the same sample positions. Only their score loops differ. Stage-zero
timeline gains expose the river and fail every other material closed. The
common player retains all seven material clocks across phase changes and
applies the monotonic stage gains through sample-time ramps. Runtime transport
tests own the render-clock, retained-player and atomic-transition proof; this
does not grant artistic, physical-device or shipping approval.

The complete runtime asset contract is sixteen files: three approach masters,
three phase-score loops, seven shared interaction material loops and three
consequence masters. A phase change therefore cannot replace or restart a
material clock.

Scoped quiet is encoded into the masters rather than represented as global
silence. The first two approach seconds and first three consequence seconds
zero score and non-river detail while preserving the gorge current. The final
200 ms of the shared interaction loop zero every non-river layer while the
current remains sample-continuous.

`distant-human-presence-v1` accepts no text or phoneme input and cannot claim
dialogue, language, chant, song, distress, individual identity or ethnic vocal
timbre. The animal layer cannot produce calls, bells, tack, gallop or panic.
The current is local procedural water, not a field recording or reconstruction.

Narration remains missing. Timed haptics are forbidden in loop beds; the
Transform reducer owns `drag`, one `break` at each committed threshold and the
durable completion `seal`. Artistic, editor, integrated narration,
stage-transport, physical-device and shipping approval remain open.

Run:

```sh
cd native/tooling
npm run render:three-records-audio
npm run validate:three-records-audio
```

Rendering performs two complete offline passes and accepts the evidence only
when every output byte matches.
