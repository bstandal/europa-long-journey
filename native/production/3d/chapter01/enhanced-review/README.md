# Chapter 01 enhanced continuity review

This directory defines a non-destructive postprocess over the five Chapter 01
continuity cells. It keeps each original USDC byte-for-byte, preserves every
canonical runtime path, hides only the old mannequin meshes and attaches a
skinned hero candidate below each existing person placeholder. The Aegean and
settlement reviews also replace the primitive cattle meshes below their
existing roots with pinned, project-authored skinned cattle candidates.

Run:

```sh
./build.sh
```

The build produces one ARKit-validated USDZ per cell and nine 9:16 review
previews across the five cells. Each package contains its stable composition
root, the exact source cell, the required shared hero and cattle layers, and
their textures in deterministic order. This preserves skinned instance sharing
without USD's unstable generated prototype numbering. The build repeats the
asset pipeline and rejects non-identical USDC or USDZ bytes.

Classification is locked to `GREYBOX_CONTINUITY_CANDIDATE` with
`finalArtGate: OPEN` and `shippingStatus: BLOCKED`. Visual QA remains failed:
the result is useful for continuity, bindings, skinned instancing and review
composition, but it is not close to simulator-candidate world art. Faces,
hands, hair, costume, cattle anatomy, deformation, exact contact, environment
art and physical-device gates remain open. The pinned character and cattle
provenance records have `rightsGate: PASS`. The source cell builders, approved
chapter material, signed package and iOS runtime are outside this pipeline and
remain untouched.
