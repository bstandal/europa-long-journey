# Chapter 01 authored 3D production

The Aegean opening continuity proof is generated by
[`scripts/build_aegean_crossing.py`](./scripts/build_aegean_crossing.py) under
Blender 5.2.0 LTS build `fbe6228777e7`. The script creates every mesh,
material, hierarchy, anchor and LOD from versioned text. It downloads nothing
and does not require a manual Blender edit.

Its locked classification is `CONTINUITY_PROOF`, with the final-art gate
`OPEN`. It proves staging, the physical seed carrier, collision-ready rope,
runtime naming, LODs and deterministic offline export. The procedural people
and bovine are not approved hero art; the centrally produced final-art rigs
must replace them before the cell can pass final visual quality.

Run:

```sh
native/production/3d/chapter01/scripts/build-aegean-crossing.sh
```

The build fails when Blender's exact version/build differs or when Pixar USD
validation fails. Canonical technical outputs live in
`generated/aegean-crossing-v1/`. Their hashes, bindings, validation results
and open gates are locked in
[`aegean-crossing-build-manifest.json`](./aegean-crossing-build-manifest.json).
The `.blend` file is an inspectable cache; the Python source remains
authoritative. “Canonical” here describes the reproducible technical output,
not final-art approval.

## Runtime naming

USD identifiers cannot contain hyphens. Blender therefore emits legal
underscore prim identifiers and preserves every runtime binding twice:

- `displayName` contains the exact hyphenated runtime name;
- `userProperties:runtime_name` contains the same canonical value.

`generated-build-report.json` records the exact runtime-name-to-USD-path map.
The cell root is `western-anatolia-aegean`. The required children include
`crossing-boat`, `action-crossing-line`, `seed-vessel`, `current-0` through
`current-3`, `western-shore`, the three named people and `young-bovine`.
`action-crossing-line` is a closed tube mesh with collision metadata, not an
empty or a render-only curve.

## Determinism and timestamps

Random construction uses seed `20260730`; topology and export traversal are
stable. The pipeline pins `SOURCE_DATE_EPOCH` and all generated filesystem and
archive times to `1980-01-01T00:00:00Z`. Canonical manifests never record a
wall-clock generation time. A release update is identified by source bytes,
tool version and SHA-256 hashes, not by when a workstation ran the build.

The art-direction PNG controls portrait staging, material weight and light. It
is not sampled, projected, included in the USD, or treated as geometry.
